## Чем занимаюсь

- **Боты и мини-приложения:** отчёты и дайджесты, напоминания, рассылки, публикации, согласования кнопками.
- **Интеграции:** amoCRM и другие CRM по REST API и вебхукам, в том числе для систем без полного публичного API.
- **ИИ в работе:** Claude Code и Claude API каждый день; ИИ-агенты внутри ботов, где любое действие «наружу» подтверждает человек.
- **Надёжность:** мониторинг, самопроверки, резервные копии, сторож и запасной сервер.
- **Опыт руководителя:** бриф и ТЗ, сметы, работа с заказчиками, команды и подрядчики.
